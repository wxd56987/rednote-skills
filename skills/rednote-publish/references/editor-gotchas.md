# 发布页踩过的坑

## 正文编辑器（ProseMirror）

- 坐标点击落点不可靠，经常点到别的段落。改字用键盘：
  - ⌘↑ / Ctrl+Home 回到开头，⇧↓ 选中整行，Backspace 删除。
  - 删改前用 `window.getSelection().toString()` 核对选中的内容。
- 输入长文用浏览器工具的 `type`，一次输完。分多次输入时，中间如果点过别处，光标可能跳走。
- 话题插入后是一个整体节点（「#xxx[话题]#」），不能只删其中几个字。

## 话题下拉

- 输入 `#ai` 后，下拉第一项常常不是 #ai 本身，而是带这个词的长话题（如「#ai时代坚持手搓的艺薯家」）。所以要按名字精确匹配，再按浏览量挑。
- 有些高浏览量话题的写法和常见拼写不同（例：GitHub 的高浏览量话题写成「#GItHub」）。精确匹配不分大小写，就能选中它。
- 「新建话题」浏览量为 0，选了等于没加。

## 图片

- 「写长文」一键排版后，模板会自动生成 1–2 张图（1440×2400），要删掉。它们的地址也是 `blob:`，只能按尺寸区分。
- 删除按钮 `.img-container .close-btn` 只在悬停时出现。用 JavaScript 直接 `click()` 最稳。
- 上传的文件名决定不了顺序，要按 01 → 02 → 03 的顺序传。

## 其它

- 「写长文」入口的 URL 带 `target=article`。没有这个参数会进「上传图文」，9.6:16 的图会留白边。
- 发布成功页 3 秒后会自动跳回发布页，验收要去「笔记管理」看。
- 「仅自己可见」的笔记，在自己登录的网页版搜索结果里也能看到，不代表别人能看到。
