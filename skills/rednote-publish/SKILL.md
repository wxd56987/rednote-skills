# 发布小红书图文笔记

在 creator.xiaohongshu.com 上用浏览器自动化发布。**默认发成「仅自己可见」**，用户在 App 里看过再自己改公开。

## 前提

- 有能操作用户浏览器、并能往网页上传本地文件的工具（如 Claude in Chrome 的 `file_upload`）。只能截图、不能上传文件的浏览器工具做不了这一步。
- 用户已在这个浏览器里登录小红书创作平台。没登录时请用户自己扫码登录，不要代填账号密码。
- 图片是 9.6:16（如 1300×2160）：必须走「写长文」。「上传图文」会把它塞进 3:4 的框，上下留白。
- `assets/page-helpers.js` 里的辅助函数要在发布页执行一次（粘贴整段运行）。

## 步骤

1. 打开 `https://creator.xiaohongshu.com/publish/publish?source=official&from=menu&target=article`，点「新的创作」。
2. **标题**：填 caption 的标题。
3. **临时正文**：先随便写 ≥100 字（如几个板块的简介），点「一键排版」→ 选默认模板 →「下一步」。等「笔记图片生成中」结束。
   正文区没接住输入时，先点一下正文区再输入，确认字数统计变了再继续。
4. **上传图片**：用 `find` 找到图片编辑区的 file input，按顺序上传（01 → 02 → 03）。
5. **删模板图**：一键排版自动生成的图也在列表里。执行 `__removeImagesNot(1300, 2160)`（参数是你的图的像素尺寸），返回值应只剩你的图。确认右侧预览铺满全宽。
6. **正文**：点正文编辑区，用键盘输入 caption 正文（不含话题），覆盖临时正文。编辑器是 ProseMirror：坐标点击不可靠，改字见 `references/editor-gotchas.md`。
7. **话题**，逐个处理：
   1. 在正文末尾输入 `#关键词`，等 2 秒出下拉。
   2. 执行 `__pickTopic('关键词')`，返回 `ok: true` 才算选上。
   3. 返回 `ok: false` 时把候选列给用户，不要选「新建话题」。
   - 最多 10 个。插入后是「#xxx[话题]#」节点；删某个话题要把光标放到该节点后面按 Backspace。
8. **内容设置**（按用户的习惯；没提过的话，第一次先问）：
   - **合集**：用户有固定的长文合集时，点「加入长文合集」（`.collection-plugin-wrapper`），在列表里选那个合集，不要新建。
   - **原创声明**：图文是用户自己原创的，并且用户要求声明原创时，打开「原创声明」（`.original-wrapper` 里的开关）。弹出须知时勾选同意再确认。
9. **核对**：执行 `__checkDraft()`，确认五点：
   - 图片数量、尺寸和顺序；
   - 话题数量 ≤ 10；
   - 正文结尾正确；
   - 没有残留的临时正文；
   - 需要原创声明时 `original: true`，要进合集时 `collection` 里有合集名。
10. **可见范围**：「更多设置」→ 可见范围选 **仅自己可见**，截图确认。
11. 点「发布」，看到「发布成功」。
12. **验收**：打开「笔记管理」，确认这篇显示「审核中」，封面上有「仅自己可见」标记。关掉自己开的标签页。
13. 告诉用户已发成仅自己可见，请用户在 App 里验收后自己改公开。

## 定时自动发布（可选）

用户要每天固定时间自动发时，用定时任务跑「出图 → 配文 → 发布」整条流程：

- **发布时间别每天一样**：用户给的是基准时间（如 8:00）。每次开始时随机抽一个偏移（如 −8 到 +12 分钟，不取 0，也不和前一天同一分钟），准备好了就停在最后一步，等到抽中的时间再点「发布」。抽到的时间写进日志。
- **任务提前启动**：留出取数、出图、修断行的时间（通常 20–40 分钟）。数据源还没更新就在后台定时重试，过了时限仍没有就不发、提醒用户，不拿旧数据凑。
- **先查今天发过没有**：笔记管理里已经有今天的标题就不重复发。
- **电脑不能睡着**：定时任务只在电脑醒着时跑。电脑整晚睡眠时，任务只能在系统的短暂唤醒（macOS Power Nap，每次几十秒）里推进，连接会反复中断，发布会拖到用户开机。「工作时保持唤醒」之类的设置叫不醒已经睡着的电脑，也拦不住合盖。macOS 上请用户自己设（需要管理员密码）：`sudo pmset repeat wakeorpoweron MTWRFSU <启动前几分钟>`（每天定时唤醒）和 `sudo pmset -c sleep 0`（接电源时不闲置睡眠），并且前一晚别合盖（接外接显示器的除外）。没按时发时，先用 `pmset -g log` 查是不是睡眠导致的。

## 修改已发布的笔记

1. 笔记管理里悬停卡片 → 铅笔图标 → 修改。
2. **换图**：
   1. 先往图片 input 追加新图（新图排在旧图后面）。
   2. 再删旧图：逐个点第一张的 `.close-btn`（用 JavaScript 点，不要用坐标）。每删一张都核对剩下的是新图（新上传的 `img.src` 以 `blob:` 开头）。
3. 点「发布」，提示「更新成功」。之后会短暂显示「审核中」，浏览数会保留。
4. 只是打开编辑页查看、不打算保存时，页面会弹「离开此网站？」拦住跳转。点左侧「笔记管理」退出即可，不会保存任何改动。

## 边界

- **改公开、删除笔记都由用户自己做。** 只有两种情况可以直接设成公开：用户明确要求某一篇直接公开发布；或者用户明确交代过以后都直接公开（比如定时自动发布）。直接公开时没有人工验收这一道，前面的核对要更严，拿不准就不发。
- 发布前有任何一项核对不过（图不对、话题超 10 个、正文残缺），先停下告诉用户，不要硬发。
- 不改账号设置、不回复私信、不点页面上的活动或推广入口。
