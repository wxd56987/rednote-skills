# data.json 字段

```jsonc
{
  "size": [1300, 2160],              // 可省略，默认 1300×2160（9.6:16）
  "pill": "AI 运营笔记 · 10.21 周三", // 左上角栏目名（右上角自动显示页码）；某页可用 pages[i].pill 覆盖
  "brand": { "id": "@your_id" },      // 页脚左侧的账号名
  "footer": {
    "note": "每日更新，建议收藏",       // 页脚账号名后面的小字；某页可用 pages[i].note 覆盖
    "next": "左滑继续 →"               // 页脚右侧；通常每页用 pages[i].next 覆盖
  },
  "theme": { },                        // 可选，覆盖默认配色，见下
  "accents": { },                      // 可选，覆盖强调色，见下
  "pages": [
    {
      "name": "01 技巧",               // 输出文件名（01 技巧.png），建议带序号保证上传顺序
      "accent": "red",                 // red / purple / blue / green（或 accents 里自定义的键）
      "title": "新手用 AI 写文案的 ",    // 大标题前半段（黑色）
      "hl": "5 个技巧",                 // 大标题高亮段（强调色），可省略
      "sub": "3 分钟看完 · 建议收藏",     // 副标题，可省略
      "next": "左滑看工作流 →",          // 页脚右侧；最后一页写「完 · 明天见」之类
      "items": [
        {
          "t": "先说读者是谁",            // 名称：尽量短，单行
          "tag": "提示词",               // 强调色描边标签，2–4 字，可省略
          "d": "开头写清**给谁看、在什么场景看**", // 一句说明，**加粗** 变黑色粗体
          "s": "适用：文案、标题、配文",    // 来源或补充（灰色小字），**加粗** 变强调色
          "v": "1 句",                   // 右侧大数字（强调色）
          "l": "加在开头"                 // 大数字下面的说明
        }
      ]
    }
  ]
}
```

## 每页条数

- 3–5 条最合适。5 条且每条说明两行时，系数约 1.2–1.3；条目少时字号到上限 1.3 为止，剩下的空间加大行距，白卡整体垂直居中。
- 一页超过 5 条会明显变小，宁可拆成两页。

## 配色覆盖

```json
"theme": { "paper": "", "sheet": "#FFFFFF", "ink": "#1D1B26", "body": "#3A3845", "muted": "#77748A", "line": "#ECEAF2" },
"accents": { "red": "#D9455F", "purple": "#7C4DDB", "blue": "#2563EB", "green": "#0F8F6B" }
```

- `paper` 留空时，每页按 `accent` 用对应的浅色底（red 浅粉、purple 浅紫、blue 浅蓝、green 浅绿）；填了就所有页统一用它。
- `sheet` 是白卡颜色，`line` 是行之间的分隔线。
- 只写要改的键。自定义强调色在白卡上的对比度不低于 4.5:1，否则序号和数值发灰。

## 「系数」怎么读

渲染时每页打印 `系数 k  余量 Npx`：

- `k`：字号缩放，范围 0.8–1.3。程序取放得下的最大值，剩余空间先加到行与行之间，再让白卡整体垂直居中。
- `k` 偏低（< 0.95）：通常是某个 `t` 太长。所有名称按同一系数缩放，只要有一条压不进一行，整页都会变小。
- 「放不下！」：最小字号也放不下，删字或减条目。
