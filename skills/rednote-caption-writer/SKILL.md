# 小红书配文

产出一个 `caption.md`：标题、正文、话题三段，格式见 `assets/caption-template.md`。

## 步骤

1. **定标题。**
   - 日更或系列内容用固定格式，便于粉丝认出，比如「MM.DD <栏目名>｜<一句承诺>」：`10.21 AI 运营笔记｜新手写文案的 5 个技巧`。账号已有固定格式时照用，不要每天换。
   - 单篇内容用「数字 + 结果」或「反常识」：`这 7 个 Skill，装完效率翻倍`。
   - 发布页会显示字数上限，超了要缩。
2. **写正文。**
   - **不要再写一遍标题**，直接从第一段内容开始。
   - 分段和图片一一对应：一页图一段，段首用一个 emoji 区分（如 🔥 / 🧩 / ⭐），每段 3–5 行。
   - 正文里的数字、名称必须与图一致，可以更口语，但不能多出图里没有的结论。
   - 结尾三行：
     - 收藏引导：「📌 数字和来源都在图里，建议先收藏」
     - 一个引导评论的问题：具体、二选一或站队类最好，比如「你写文案时最常卡在哪一步：开头、结构还是结尾？」
     - 关注引导：「每天更新，关注 @账号 不错过」
3. **选话题。**
   - 最多 10 个（平台上限，超过时点发布会报错）。
   - 组成：4–6 个领域大词（如 #ai #人工智能 #AI工具 #效率工具）+ 2–4 个和这篇内容直接相关的（如 #文案写作 #小红书运营）。
   - 只写话题名，选具体哪个同名话题在发布时做（rednote-publish 会挑浏览量最大的那个）。
4. **合规自查**（任何一条不满足都要改）：
   - 没有外链、二维码、微信号、「私信领取」「评论区扣 1」之类的站外导流。
   - 没有收入、定价、「怎么赚钱」「副业」类引导。
   - 单一来源或未证实的数字，正文里也要说「据报」「待核实」。
   - 涉及投资、交易：写「仅供研究，不构成投资建议」。
5. 把 `caption.md` 交给用户确认，或交给 rednote-publish。
